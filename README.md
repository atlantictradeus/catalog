# 📦 Atlantic Trade - Global B2B Catalog & Import-Exporter Portal

This repository contains the source code and media assets for the public service and product catalog of **[Atlantic Trade](https://atlantictrade.us)**, a premier B2B commercial catalog and trade facilitation bridge for North America.

---

## 🗺️ Core Industries & Categories

Our directory indexes verified suppliers across 19 core B2B industries, including Machines & Equipment, Windows & Doors, Agriculture & Breeding, Building Materials, Chemicals & Pharma, and Transport & Logistics.

---

## 🛠️ Repository & Project Structure

The project assets are organized for rapid navigation and structured catalog updates for global verified suppliers (from Ukraine, Poland, Turkey, India, Azerbaijan, and Uzbekistan), featuring asset directories like `machinery and equipments/`, `concrete pump/`, and `README.md`.
